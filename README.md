# Yolo_v8
This repository utilizes YOLOv8 for object detection and segmentation in images and videos. It does not include any training or fine-tuning; instead, it uses pre-trained models. The implementation is provided in two ways: via command-line execution and Python scripting. To run and use YOLOv8, simply execute the notebook in Google Colab. After connecting Colab to your Google Drive, place your image and video files inside the input folder.
